# Progress

How far a task has gone, with an optional label and value. The track is bordered in Iwa.

<ComponentPreview name="progress" />

## Installation

```bash title="Terminal"
npx rasengan-ui add progress
```

Or with the shadcn CLI, from the registry:

```bash title="Terminal"
npx shadcn@latest add https://registry.rasengan.dev/r/base/progress.json
```

<Note title="Not published yet">
  The `rasengan-ui` CLI and the registry address above come with the first release. Until then, run `pnpm registry` in
  this repository and add from `http://localhost:3200/r/base/progress.json`.
</Note>

## Usage

```tsx title="app/upload.tsx"
import { Progress, ProgressLabel, ProgressValue } from "@/components/ui/progress";

export function Upload({ value }: { value: number }) {
  return (
    <Progress value={value} className="w-72">
      <ProgressLabel>Uploading</ProgressLabel>
      <ProgressValue />
    </Progress>
  );
}
```

### Indeterminate

`value={null}` when the end can't be known yet.

## Villages

The track is muted with `--track-border`, the indicator the nature's primary; its width animates with the village's motion.

## Accessibility

- A `progressbar` with `aria-valuenow`, named by `ProgressLabel`; `ProgressValue` shows the formatted value.

## API reference

The parts of Base UI's [Progress](https://base-ui.com/react/components/progress):

| Part | Notes |
| --- | --- |
| `Progress` | `value` (`null` for indeterminate), `min`, `max`, `format`; draws the track and indicator after its children |
| `ProgressLabel` | names the bar |
| `ProgressValue` | the formatted value |
