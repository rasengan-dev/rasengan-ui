# Alert

A message in the flow of the page: information, or an error with its destructive colour. For a message that floats over the page, use [Toast](/components/toast).

<ComponentPreview name="alert" />

## Installation

```bash title="Terminal"
npx rasengan-ui add alert
```

Or with the shadcn CLI, from the registry:

```bash title="Terminal"
npx shadcn@latest add https://registry.rasengan.dev/r/base/alert.json
```

<Note title="Not published yet">
  The `rasengan-ui` CLI and the registry address above come with the first release. Until then, run `pnpm registry` in
  this repository and add from `http://localhost:3200/r/base/alert.json`.
</Note>

## Usage

```tsx title="app/heads-up.tsx"
import { InfoIcon } from "lucide-react";
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

export function Heads() {
  return (
    <Alert>
      <InfoIcon />
      <AlertTitle>Heads up</AlertTitle>
      <AlertDescription>You can switch village at any time from the settings.</AlertDescription>
    </Alert>
  );
}
```

### Variants and tones

`default` is a card; `soft` washes it in the tone; `outline` drops the fill for a border in the tone. `tone` is
`neutral` by default (the village's ink), or `primary`, `success`, `warning`, `info`, `destructive`: on `default` it
colours the icon and the title, on `soft` and `outline` the surface too. The description stays in the page's text
colour, so it reads at full contrast.

<ComponentPreview name="alert" demo="alert-variants" />

```tsx
<Alert variant="soft" tone="success" role="status">…</Alert>
```

### Destructive

`variant="destructive"`, as in shadcn, colours the title, the icon, the description and the border.

## Accessibility

- It has `role="alert"`, so a screen reader announces it as soon as it appears. For a message present from the start that needs no announcement, pass `role="status"` or `role="note"`.

## API reference

`Alert`, `AlertTitle` and `AlertDescription`, each a `<div>`. `Alert` takes:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "soft" \| "outline" \| "destructive"` | `"default"` |
| `tone` | `"neutral" \| "primary" \| "success" \| "warning" \| "info" \| "destructive"` | `"neutral"` |
