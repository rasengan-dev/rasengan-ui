# Switch

Turns a setting on or off, with an immediate effect. When the change waits for a Save button, use a [Checkbox](/components/checkbox).

<ComponentPreview name="switch" />

## Installation

```bash title="Terminal"
npx rasengan-ui add switch
```

Or with the shadcn CLI, from the registry:

```bash title="Terminal"
npx shadcn@latest add https://ui.rasengan.dev/r/base/switch.json
```

## Usage

```tsx title="app/notifications.tsx"
import { Label } from "@/components/ui/label";
import { Switch } from "@/components/ui/switch";

export function Notifications() {
  return (
    <div className="flex items-center gap-2">
      <Switch id="notifications" defaultChecked />
      <Label htmlFor="notifications">Notifications</Label>
    </div>
  );
}
```

### Tones

`tone` colours the checked track, and the thumb takes the text colour that sits on it: `primary` by default, or `neutral`, `success`, `warning`, `info`, `destructive`. The thumb, at 4.5:1 on the track, is what shows the state.

<ComponentPreview name="switch" demo="switch-tones" />

### Sizes

`sm`, `default` and `lg`; the thumb's travel follows the size and the village's border.

<ComponentPreview name="switch" demo="switch-sizes" />

## Villages

The track and thumb are village tokens (`--switch-track`, `--switch-thumb`, `--track-border`): Iwa borders its track and draws its thumb in ink, without a shadow.

<VillageGrid name="switch" />

## Accessibility

- A `role="switch"` button with `aria-checked`, backed by a hidden input for forms.
- <kbd>Space</kbd> and <kbd>Enter</kbd> toggle it; a linked label toggles it on click.

## API reference

The props of Base UI's [Switch](https://base-ui.com/react/components/switch) root (`checked`, `defaultChecked`, `onCheckedChange`, `name`, `required`, `disabled`…), plus:

| Prop | Type | Default |
| --- | --- | --- |
| `tone` | `"neutral" \| "primary" \| "success" \| "warning" \| "info" \| "destructive"` | `"primary"` |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` |
| `className` | `string` | |

`switchVariants({ tone, size })` returns the track's classes.
