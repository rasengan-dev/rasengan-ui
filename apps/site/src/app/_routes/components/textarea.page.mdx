# Textarea

A multi-line text field, styled like [Input](/components/input) and wired into a [Field](/components/field) the same way. It grows with its content (`field-sizing: content`) and can be resized vertically.

<ComponentPreview name="textarea" />

## Installation

```bash title="Terminal"
npx rasengan-ui add textarea
```

Or with the shadcn CLI, from the registry:

```bash title="Terminal"
npx shadcn@latest add https://ui.rasengan.dev/r/base/textarea.json
```

<Note title="Not published yet">
  The `rasengan-ui` CLI and the registry address above come with the first release. Until then, run `pnpm registry` in
  this repository and add from `http://localhost:3200/r/base/textarea.json`.
</Note>

## Usage

```tsx title="app/feedback.tsx"
import { Field, FieldLabel } from "@/components/ui/field";
import { Textarea } from "@/components/ui/textarea";

export function Feedback() {
  return (
    <Field>
      <FieldLabel>What changed?</FieldLabel>
      <Textarea placeholder="Tell the team what changed…" />
    </Field>
  );
}
```

### Variants

The input's three variants: `default`, `filled` and `underline`.

<ComponentPreview name="textarea" demo="textarea-variants" />

### Sizes

`sm`, `default` and `lg` set the padding, the text and the starting height (4, 6 and 8 lines' worth); the textarea then
grows with its content. Inside a [Field](/components/field), it takes the Field's `size` and `variant`.

## Accessibility

- A `<textarea>`, rendered by Base UI's Field control: a Field labels and describes it.
- Invalid and disabled states work as on Input.

## API reference

The props of `<textarea>`, plus:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "filled" \| "underline"` | the Field's, else `"default"` |
| `size` | `"sm" \| "default" \| "lg"` | the Field's, else `"default"` |
| `className` | `string` | |

`textareaVariants({ variant, size })` returns its classes.
