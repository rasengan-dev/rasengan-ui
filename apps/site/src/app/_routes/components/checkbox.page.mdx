# Checkbox

Turns an option on or off, with an indeterminate state for “some of these”. Square in every village, rounder in Konoha and Kiri, sharp in Iwa.

<ComponentPreview name="checkbox" />

## Installation

```bash title="Terminal"
npx rasengan-ui add checkbox
```

Or with the shadcn CLI, from the registry:

```bash title="Terminal"
npx shadcn@latest add https://registry.rasengan.dev/r/base/checkbox.json
```

<Note title="Not published yet">
  The `rasengan-ui` CLI and the registry address above come with the first release. Until then, run `pnpm registry` in
  this repository and add from `http://localhost:3200/r/base/checkbox.json`.
</Note>

## Usage

```tsx title="app/updates.tsx"
import { Checkbox } from "@/components/ui/checkbox";
import { Label } from "@/components/ui/label";

export function Updates() {
  return (
    <div className="flex items-center gap-2">
      <Checkbox id="updates" defaultChecked />
      <Label htmlFor="updates">Email me product updates</Label>
    </div>
  );
}
```

### Indeterminate

`indeterminate` draws a dash, for a parent checkbox whose children are partly checked. Base UI's `CheckboxGroup` can
manage such a parent for you (`parent` on the parent checkbox).

```tsx
<Checkbox indeterminate aria-label="Select all" />
```

## Villages

The box takes the village's check radius and border width; checked, it fills with the nature's primary.

## Accessibility

- A `role="checkbox"` button with `aria-checked` (`mixed` when indeterminate), backed by a hidden input for forms.
- <kbd>Space</kbd> toggles it; a linked label toggles it on click.
- Inside a Field, an invalid checkbox (a `required` one left unchecked) turns destructive.

## API reference

The props of Base UI's [Checkbox](https://base-ui.com/react/components/checkbox) root (`checked`, `defaultChecked`, `onCheckedChange`, `indeterminate`, `name`, `value`, `required`, `disabled`…), plus `className`.
