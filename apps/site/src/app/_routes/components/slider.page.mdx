# Slider

Picks a value, or a range with two thumbs, along a track. Keyboard steps with the arrows, large steps with Page Up and Down.

<ComponentPreview name="slider" />

## Installation

```bash title="Terminal"
npx rasengan-ui add slider
```

Or with the shadcn CLI, from the registry:

```bash title="Terminal"
npx shadcn@latest add https://ui.rasengan.dev/r/base/slider.json
```

## Usage

```tsx title="app/volume.tsx"
import { Slider } from "@/components/ui/slider";

export function Volume() {
  return <Slider defaultValue={40} aria-label="Volume" className="w-64" />;
}
```

### Range

Pass an array to get one thumb per value. `minStepsBetweenValues` keeps the thumbs apart.

```tsx
<Slider defaultValue={[20, 80]} step={5} aria-label="Price range" />
```

### Tones

`tone` colours the range and the thumb's ring: `primary` by default. The ring takes the tone's edge, 3:1 on the page even for `warning`.

<ComponentPreview name="slider" demo="slider-tones" />

### Sizes

`sm`, `default` and `lg` set the track's thickness and the thumb, at the village's indicator sizes.

## Accessibility

- Each thumb is a `slider` with `aria-valuenow`; `aria-label` on the Slider names every thumb.
- Arrow keys move by `step`, <kbd>Page Up</kbd> and <kbd>Page Down</kbd> by `largeStep`, <kbd>Home</kbd> and <kbd>End</kbd> to the ends.

## API reference

The props of Base UI's [Slider](https://base-ui.com/react/components/slider) root (`value`, `defaultValue`, `onValueChange`, `onValueCommitted`, `min`, `max`, `step`, `largeStep`, `minStepsBetweenValues`, `orientation`, `disabled`…), plus `tone` (`"neutral" \| "primary" \| "success" \| "warning" \| "info" \| "destructive"`, default `"primary"`), `size` (`"sm" \| "default" \| "lg"`) and `className`. Its track, range and thumbs are drawn for you; `sliderVariants({ tone, size })` returns the root's classes.
