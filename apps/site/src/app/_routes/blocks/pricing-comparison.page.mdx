## Installation

```bash title="Terminal"
npx rasengan-ui add pricing-comparison
```

It installs into `components/blocks/pricing-comparison/`, with what it uses (Badge, Button, Table) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { PricingComparison } from "@/components/blocks/pricing-comparison";
import { home } from "@/content/home";

export default function Home() {
  return <PricingComparison content={home.compare} />;
}
```

```ts title="content/home.ts"
import { example, type PricingComparisonContent } from "@/components/blocks/pricing-comparison";

export const home = {
  compare: { ...example, title: "Every feature, every plan" } satisfies PricingComparisonContent,
};
```

Each row gives one value per plan, in the plans' order: `true` (a tick), `false` (a dash) or a short text (`"Up to 5"`). The schema refuses a row with too few or too many. The highlighted plan is tinted down its column. In a narrow container the table scrolls sideways, the feature column staying in place.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `PricingComparisonContent`; the example when left out |
| `id` | the section's id, for anchor links; `"compare"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the `<section>`, for spacing |

## Accessibility

- A real table: plans are column headers, features row headers, groups `colgroup` headers.
- Ticks and dashes are read as `labels.included` and `labels.notIncluded`.
