## Installation

```bash title="Terminal"
npx rasengan-ui add hero-product
```

It installs into `components/blocks/hero-product/`, with what it uses (Device Frame, Badge, Button), `lib/blocks.ts` and `lib/motion.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example as it is):

```tsx title="app/_routes/index.page.tsx"
import { HeroProduct } from "@/components/blocks/hero-product";
import { home } from "@/content/home";

export default function Page() {
  return <HeroProduct content={home.hero} />;
}
```

```ts title="content/home.ts"
import { example, type HeroProductContent } from "@/components/blocks/hero-product";

export const home = {
  hero: { ...example } satisfies HeroProductContent,
};
```

A headline, its actions and a note on a soft panel of the primary colour, and the product's screen in a browser frame (Device Frame) rising out of it, with the address you give in `url`. The screen is wider than the text and the panel's bottom edge cuts it, where it fades: put what matters in its top two thirds. A screenshot at 16:10 reads best; it loads first.

As the page scrolls the screen settles into place, at rest once it reaches the middle of the viewport: it grows and rises in every village that allows travel (intensity 2), and straightens from a tilt in the showcase ones (intensity 3). With reduced motion it is at rest from the start.

For a still screenshot under the headline, use [hero-centered](/blocks/hero-centered).

The [SaaS example](/examples/saas) uses it.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `HeroProductContent`; the example when left out |
| `id` | the section's id, for anchor links; `"hero"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `1` by default |
| `className` | on the section, for spacing |

## Accessibility

- The screenshot keeps its `alt`: say what the screen shows.
- The panel and the frame's chrome are decoration.
- The screen moves only with the reader's scroll, and not at all with reduced motion.
