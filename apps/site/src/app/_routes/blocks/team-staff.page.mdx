## Installation

```bash title="Terminal"
npx rasengan-ui add team-staff
```

It installs into `components/blocks/team-staff/`, with what it uses (Badge, Button) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { TeamStaff } from "@/components/blocks/team-staff";
import { home } from "@/content/home";

export default function Home() {
  return <TeamStaff content={home.team} />;
}
```

```ts title="content/home.ts"
import { example, type TeamStaffContent } from "@/components/blocks/team-staff";

export const home = {
  team: { ...example, title: "Meet the team" } satisfies TeamStaffContent,
};
```

Each member can have a booking link (`cta`): point it at your booking form (`#booking`) or a message. A member without a photo shows their initials.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `TeamStaffContent`; the example when left out |
| `id` | the section's id, for anchor links; `"team"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the `<section>`, for spacing |

## Accessibility

- Portraits have their own `alt`; the initials tile is hidden from screen readers, the name is read below it.
