## Installation

```bash title="Terminal"
npx rasengan-ui add gallery-grid
```

It installs into `components/blocks/gallery-grid/`, with what it uses ([Lightbox](/components/lightbox), which brings Dialog and Button) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { GalleryGrid } from "@/components/blocks/gallery-grid";
import { home } from "@/content/home";

export default function Home() {
  return <GalleryGrid content={home.gallery} />;
}
```

```ts title="content/home.ts"
import { example, type GalleryGridContent } from "@/components/blocks/gallery-grid";

export const home = {
  gallery: {
    ...example,
    title: "The place",
  } satisfies GalleryGridContent,
};
```

The first photo is shown two by two. A photo opens full screen in a Lightbox, with its caption; the arrows, the arrow keys and a swipe move to the others. Captions also show over the photo on hover and focus.

Since 2026-11-24 the photos open in a [Lightbox](/components/lightbox), no longer in the block's own Dialog. The
block's markup moved inside the Lightbox, one level deeper, so an edit anywhere in it comes back from
`rasengan-ui update` between conflict markers rather than merged: nothing is lost. Keep the registry's side and make
your edit again in it.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `GalleryGridContent`; the example when left out |
| `id` | the section's id, for anchor links; `"gallery"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the `<section>`, for spacing |

## Accessibility

- Each photo is a button named by its `alt`; the Lightbox is a Dialog: it traps focus, closes with Escape and gives focus back to the photo.
- The previous and next buttons are named by `labels`.
