## Installation

```bash title="Terminal"
npx rasengan-ui add gallery-grid
```

It installs into `components/blocks/gallery-grid/`, with what it uses (Dialog, Button) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { GalleryGrid } from "@/components/blocks/gallery-grid";
import { home } from "@/content/home";

export default function Home() {
  return <GalleryGrid content={home.gallery} />;
}
```

```ts title="content/home.ts"
import { example, type GalleryGridContent } from "@/components/blocks/gallery-grid";

export const home = {
  gallery: {
    ...example,
    title: "The place",
  } satisfies GalleryGridContent,
};
```

The first photo is shown two by two. A photo opens in a Dialog, large, with its caption; the arrows and the arrow keys move to the others. Captions also show over the photo on hover and focus.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `GalleryGridContent`; the example when left out |
| `id` | the section's id, for anchor links; `"gallery"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the `<section>`, for spacing |

## Accessibility

- Each photo is a button named by its `alt`; the Dialog traps focus and closes with Escape.
- The previous and next buttons are named by `labels`.
