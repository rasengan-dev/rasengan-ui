# Blocks

Page sections built on the components: a hero, a pricing table, a menu, opening hours. Each takes its content as one
typed object, checked by a schema, so you or an agent fill it in without touching the layout. Install one and its code
is yours, like a component's; it follows the village and the nature you picked.

```bash title="Terminal"
npx rasengan-ui add cta-banner
```

Blocks answer the width of their container, not the window's: the same block lays out as a phone column in a sidebar
and as a full row on a wide page.
