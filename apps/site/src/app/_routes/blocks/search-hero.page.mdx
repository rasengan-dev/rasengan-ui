## Installation

```bash title="Terminal"
npx rasengan-ui add search-hero
```

It installs into `components/blocks/search-hero/`, with what it uses (Input, Select, Chip, Button, Field), `lib/blocks.ts` and `lib/filters.ts).

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example as it is):

```tsx title="app/_routes/homes/index.page.tsx"
import { SearchHero } from "@/components/blocks/search-hero";
import { ListingCards } from "@/components/blocks/listing-cards";
import { homes } from "@/content/homes";

export default function Page() {
  return (
    <>
      <SearchHero content={homes.search} />
      <ListingCards content={homes.cards} />
    </>
  );
}
```

```ts title="content/homes.ts"
import { example, type SearchHeroContent } from "@/components/blocks/search-hero";

export const homes = {
  search: { ...example } satisfies SearchHeroContent,
};
```

A real form: it is sent with GET to `action`, the list page and its section (`/homes#listings`), so it works without JavaScript. On that page itself, it does not reload: it writes the search in the address (`?q=…&kind=…&place=…`, through `lib/filters.ts`) and scrolls to the list, which [listing-cards](/blocks/listing-cards) filters in place. Its fields show the search the address holds.

The words are looked for in the listings' titles, kinds, places, tags and lines; the type and the place keep the listings whose own contains the choice (`Douala` keeps `Bonapriso, Douala`). Each suggestion is a link to a search already made.

The [homes example](/examples/homes) uses it.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `SearchHeroContent`; the example when left out |
| `id` | the section's id, for anchor links; `"search"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `1` by default |
| `className` | on the section, for spacing |

## Accessibility

- The form is a search landmark, named by `labels.search`; each field has its label.
- The photo keeps its `alt`; the panel sits beside it in the reading order, not over its text.
