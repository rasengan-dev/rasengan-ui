## Installation

```bash title="Terminal"
npx rasengan-ui add testimonials-marquee
```

It installs into `components/blocks/testimonials-marquee/`, with what it uses (Marquee) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example as it is):

```tsx title="app/_routes/index.page.tsx"
import { TestimonialsMarquee } from "@/components/blocks/testimonials-marquee";
import { home } from "@/content/home";

export default function Page() {
  return <TestimonialsMarquee content={home.testimonials} />;
}
```

```ts title="content/home.ts"
import { example, type TestimonialsMarqueeContent } from "@/components/blocks/testimonials-marquee";

export const home = {
  testimonials: { ...example } satisfies TestimonialsMarqueeContent,
};
```

Six to twenty-four short quotes, alternating between two rows that slide in opposite directions at different speeds and fade into the edges. Each row stops on hover and focus and has a pause button; with reduced motion the rows stand still and wrap.

For quotes in columns that drift upwards together, use [testimonials-wall](/blocks/testimonials-wall).

The [SaaS example](/examples/saas) uses it.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `TestimonialsMarqueeContent`; the example when left out |
| `id` | the section's id, for anchor links; `"testimonials"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the section, for spacing |

## Accessibility

- Each moving list is a named region with a pause button (WCAG 2.2.2).
- Marquee's copies are hidden from screen readers, so each quote is read once.
