## Installation

```bash title="Terminal"
npx rasengan-ui add testimonials-wall
```

It installs into `components/blocks/testimonials-wall/`, with what it uses (Marquee) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { TestimonialsWall } from "@/components/blocks/testimonials-wall";
import { home } from "@/content/home";

export default function Home() {
  return <TestimonialsWall content={home.testimonials} />;
}
```

```ts title="content/home.ts"
import { example, type TestimonialsWallContent } from "@/components/blocks/testimonials-wall";

export const home = {
  testimonials: { ...example, title: "What studios say" } satisfies TestimonialsWallContent,
};
```

On a wide screen the three columns drift slowly upwards together, inside one Marquee: it stops on hover and focus and has a pause button. With motion off, or at intensity 0, the wall stands still and scrolls inside its height. On a narrow screen it is one or two still columns. Mix short and long quotes; nine or more fill the wall.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `TestimonialsWallContent`; the example when left out |
| `id` | the section's id, for anchor links; `"testimonials"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the `<section>`, for spacing |

## Accessibility

- The moving wall is a named region (`label`) with a pause button (WCAG 2.2.2).
- Avatars are decoration: each quote names its author in text.
