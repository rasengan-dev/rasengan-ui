## Installation

```bash title="Terminal"
npx rasengan-ui add pricing-plans
```

It installs into `components/blocks/pricing-plans/`, with what it uses (Card, Badge, Button, Toggle group, Number roll) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { PricingPlans } from "@/components/blocks/pricing-plans";
import { home } from "@/content/home";

export default function Home() {
  return <PricingPlans content={home.pricing} />;
}
```

```ts title="content/home.ts"
import { example, type PricingPlansContent } from "@/components/blocks/pricing-plans";

export const home = {
  pricing: {
    ...example,
    title: "Your section title",
  } satisfies PricingPlansContent,
};
```

### Monthly and yearly

With `billing`, a switch above the plans changes every monthly plan to its yearly price, and each price rolls to its
new amount with Number roll (with motion off, it simply changes). A plan's `yearly` is the price of a whole year;
left out, it is twelve months of `price`. Plans billed `once` keep their price. Leave `billing` out for plans that
have only one period.

```ts
billing: { label: "Billing period", month: "Monthly", year: "Yearly", saving: "2 months free" },
plans: [{ name: "Studio", price: { amount: 19, currency: "USD" }, period: "month", yearly: { amount: 190, currency: "USD" } /* … */ }],
```

Prices are formatted with `Intl.NumberFormat` in `locale`: `{ amount: 19, currency: "EUR" }` reads "19,00 €" in `fr-FR`.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `PricingPlansContent`; the example when left out |
| `id` | the section's id, for anchor links; `"pricing"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the root element, for spacing |

## Accessibility

- Plans are a list; each plan's name is a heading one level below the block's.
- The highlighted plan is marked by its badge's text, not only by its colour.
- The billing switch is a toggle group named by `billing.label`; the chosen option is pressed (`aria-pressed`).
- Screen readers read each price once, formatted, not its rolling digits.
