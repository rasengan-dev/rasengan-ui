## Installation

```bash title="Terminal"
npx rasengan-ui add menu-list
```

It installs into `components/blocks/menu-list/`, with what it uses (Badge) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { MenuList } from "@/components/blocks/menu-list";
import { home } from "@/content/home";

export default function Home() {
  return <MenuList content={home.menu} />;
}
```

```ts title="content/home.ts"
import { example, type MenuListContent } from "@/components/blocks/menu-list";

export const home = {
  menu: { ...example, title: "À la carte" } satisfies MenuListContent,
};
```

Every category is shown: they flow into two columns on a wide screen and never break across them. For a long menu, `menu-categories` puts each category in a tab.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `MenuListContent`; the example when left out |
| `id` | the section's id, for anchor links; `"menu"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the `<section>`, for spacing |

## Accessibility

- Category names are headings one level below the title.
- The dotted leaders are hidden from screen readers: a dish is read as its name, then its price.
