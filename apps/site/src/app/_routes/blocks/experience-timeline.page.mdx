## Installation

```bash title="Terminal"
npx rasengan-ui add experience-timeline
```

It installs into `components/blocks/experience-timeline/`, with `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example as it is):

```tsx title="app/_routes/index.page.tsx"
import { ExperienceTimeline } from "@/components/blocks/experience-timeline";
import { studio } from "@/content/studio";

export default function Page() {
  return <ExperienceTimeline content={studio.experience} />;
}
```

```ts title="content/studio.ts"
import { example, type ExperienceTimelineContent } from "@/components/blocks/experience-timeline";

export const studio = {
  experience: { ...example } satisfies ExperienceTimelineContent,
};
```

Two to sixteen entries, newest first: from and to (a year, `2021`, or a month, `2021-03`, or `now`), what it was, where, and a line. Months are written in `locale` (`Mar 2021` in English), the same on the server and in the browser.

The [portfolio example](/examples/portfolio) uses it, with its content in one file.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `ExperienceTimelineContent`; the example when left out |
| `id` | the section's id, for anchor links; `"experience"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the section, for spacing |

## Accessibility

- An ordered list; each entry's dates are `<time>` elements with their ISO value.
- Each title is a heading one level below the block's.
