## Installation

```bash title="Terminal"
npx rasengan-ui add footer-columns
```

It installs into `components/blocks/footer-columns/`, with what it uses (Separator) and `lib/blocks.ts`.

## Usage

Without `content`, the block shows its example. Pass your own, typed by the block's schema, from a content file (here, the example with one field changed):

```tsx title="app/_routes/index.page.tsx"
import { FooterColumns } from "@/components/blocks/footer-columns";
import { home } from "@/content/home";

export default function Home() {
  return <FooterColumns content={home.footer} />;
}
```

```ts title="content/home.ts"
import { example, type FooterColumnsContent } from "@/components/blocks/footer-columns";

export const home = {
  footer: {
    ...example,
    legal: "© 2026 Your company",
  } satisfies FooterColumnsContent,
};
```

Column titles are headings at `headingLevel`, styled small.

## Props

| Prop | Notes |
| --- | --- |
| `content` | `FooterColumnsContent`; the example when left out |
| `id` | the footer's id, for anchor links; `"footer"` by default |
| `headingLevel` | `1`, `2` or `3`: the heading's tag; `2` by default |
| `className` | on the root element, for spacing |

## Accessibility

- A `<footer>`: the page's contentinfo landmark when it sits outside `<main>`.
- Each column is a `<nav>` named by its title.
