# Proposals

Significant changes to Rasengan UI start as an RFC in this folder: what changes, why, and how, settled before
implementation. `Status` goes from `Draft` to `Accepted` to `Implemented`.

| RFC | Title | Status |
|---|---|---|
| [RFC-0001](RFC-0001-Rasengan-UI-v2.md) | Rasengan UI v2 — animated blocks an agent can compose | Superseded by RFC-0002, except the block content contract |
| [RFC-0002](RFC-0002-Rasengan-UI-Villages.md) | Rasengan UI — components on Base UI, themed by villages | Draft |
